# 新浪财经 7x24 查看器

[English README](./README.md)

这是一个通过同源代理浏览新浪财经 7x24 直播流的小型 Web 项目。普通界面位于 `/`，精简的文本时间线界面位于 `/legacy`。

## 功能

- 通过同源代理浏览新浪财经 7x24 数据流
- 按正文、消息 ID、时间文本、来源、评论和标签搜索、过滤
- 将标题与末尾来源提取为单独显示区域
- 在普通界面的独立弹窗中查看原始属性和评论数据
- 自动刷新最新消息；单次最多重试两次；后台标签页暂停轮询，返回前台后立即刷新
- 第三方数据以文本方式渲染，图片和原文链接只允许 HTTP(S) 地址
- 访问 `/legacy` 进入精简时间线：默认最多显示 100 条新闻；不显示单条评论和原文链接，底部按钮会解除限制并解锁项目上限调整，离开精简模式或刷新页面后恢复锁定

## 项目结构

- `index.html` — 页面骨架与静态挂载点
- `scripts/core/viewer-core.js` — 数据流生命周期、过滤、渲染、统计和弹窗
- `scripts/app.js` — 前端启动入口
- `styles/` — 页面样式
- `backend/core/` — 运行时无关的后端处理器与共享校验规则
- `server/` — 本地 Node 适配层与应用装配
- `functions/` — 无服务器 API 适配层路由
- `ARCHITECTURE.md` — 模块级架构说明

## 环境要求

- Node.js 18 或更高版本

## 本地开发

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:3000`。

打开 `http://127.0.0.1:3000/legacy` 可进入精简模式。

如果只是普通本地运行，不需要 watch 模式：

```bash
npm start
```

## HTTP 接口

- `GET /` — 普通查看器页面
- `GET /legacy` — 精简查看器页面
- `GET /healthz` — 健康检查
- `/api/zhibo/*` — 代理到新浪 7x24 接口
- `GET /api/avatar?url=...` — 白名单头像代理
