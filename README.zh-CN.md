# 新浪财经 7x24 查看器

[English README](./README.md)

这是一个通过同源代理浏览新浪财经 7x24 直播流的小型 Web 项目。普通界面位于 `/`，精简的文本时间线界面位于 `/legacy`。

## 功能

- 通过同源代理浏览新浪财经 7x24 数据流
- 按正文、消息 ID、时间文本搜索
- 通过主下拉按“评论：有”“来源：有”和标签分类过滤，并提供单独的焦点按钮
- 将标题与末尾来源提取为单独显示区域
- 在普通界面的独立弹窗中查看原始属性和评论数据
- 自动刷新最新消息；单次最多重试两次；后台标签页暂停轮询，返回前台后立即刷新
- 普通界面通过顶部粘性控制面板切换项目上限和最新刷新行为
- 搜索框获得焦点时保持普通界面的控制面板展开，避免窄屏重排造成跳动
- 窄屏下，普通界面的新闻标签和操作按钮保持紧凑并按内容宽度排列，必要时自然换行
- 将新浪最新字段合并到已有项目，并在可见内容变化时更新显示
- 第三方数据以文本方式渲染，图片和原文链接只允许 HTTP(S) 地址
- 控件具有可访问名称和切换状态，弹窗支持键盘焦点进入、回环和返回
- 首次成功加载前显示加载状态，首次加载失败时明确显示失败状态而非零统计
- 访问 `/legacy` 进入精简时间线：默认最多显示 100 条新闻；不显示单条评论和原文链接，底部解锁只在本次停留精简模式期间有效
- 精简模式工具栏跟随页面正常滚动
- 右下角快捷暂停按钮与“更多设置”中的“新数据刷新”按钮共用状态并相互联动；历史消息分页仍保持自动加载
- 通过白名单头像代理安全加载头像资源，并拒绝上游重定向
- 同时支持本地 Express 路由和 Pages Functions 风格的无服务器路由

## 项目结构

- `index.html` — 页面骨架与静态挂载点
- `scripts/core/viewer-core.js` — 数据流生命周期、过滤、渲染、统计和弹窗
- `scripts/app.js` — 前端启动入口
- `styles/` — 页面样式
- `backend/core/` — 运行时无关的后端处理器与共享校验规则
- `server/` — 本地 Node 适配层与应用装配
- `functions/` — 无服务器 API 适配层路由
- `ARCHITECTURE.md` — 模块级架构说明

## 环境要求

- Node.js 18 或更高版本

## 本地开发

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:3000`。

打开 `http://127.0.0.1:3000/legacy` 可进入精简模式。本地服务端会在返回 HTML 时预先加入精简模式 class，因此浏览器首屏不会先闪现普通界面。

如果只是普通本地运行，不需要 watch 模式：

```bash
npm start
```

## HTTP 接口

- `GET /` — 普通查看器页面
- `GET /legacy` — 精简查看器页面
- `GET /healthz` — 健康检查
- `/api/zhibo/*` — 代理到新浪 7x24 接口
- `GET /api/avatar?url=...` — 白名单头像代理
