# 新浪财经 7x24 查看器

[English README](./README.md)

这是一个通过同源代理浏览新浪财经 7x24 直播流的小型 Web 应用。

## 功能

- 在普通页面 / 浏览实时新闻。
- 在精简页面 /legacy 浏览文本时间线。
- 按正文、消息 ID、时间和标签搜索、过滤；另有单独的“有评论”筛选。
- 向下滚动加载更早新闻。
- 自动或手动刷新最新新闻。
- 最新新闻刷新时尽量保持阅读位置。
- 搜索结果变化时复用已有新闻卡片，避免每次输入都重建整份列表。
- 兼容中文输入法组合输入，组合过程中不会反复筛选。
- 在普通模式查看新闻属性和评论。
- 安全渲染上游文本，只允许 HTTP(S) 图片和原文链接。

即使上游总页数不可靠，查看器也会继续尝试历史分页。遇到空页、响应页码不再前进、重复页面或超过单次安全上限时会安全停止。

可选的 100 条上限只保留最新项目并维护阅读锚点。解除上限后会从第一个历史页重新加载，并按消息 ID 去重，避免跳过旧新闻。

## 搜索

搜索框使用大小写不敏感的字面子串匹配。直接输入要查找的文字，不支持字段前缀、布尔运算符或其他查询语法。

可以搜索：

- 新闻完整正文，包括正文中包含的来源文字；
- 新闻 ID；
- 接口原始时间、页面显示时间和 YYYY-MM-DD 日期；
- 标签 ID 和标签名称。

例如可以输入 5102090、18:43、2026-09-18 或标签名称。

## 环境要求

- Node.js 18 或更高版本

## 本地运行

安装依赖：

    npm install

启动开发服务器：

    npm run dev

打开 http://127.0.0.1:3000/。

打开 http://127.0.0.1:3000/legacy 进入精简模式。

普通启动：

    npm start

## 刷新行为

- 首次加载、手动刷新、隐藏不超过 24 小时后返回：请求最新 100 条。
- 页面内自动刷新：请求最新 30 条。
- 自动刷新间隔可设置为 1 秒至 24 小时。
- 每次请求在初次尝试后最多重试两次。
- 窗口仅失焦但仍可见时继续刷新。
- 隐藏超过 24 小时后返回需要手动刷新。

## 测试和依赖检查

运行回归测试：

    npm test

检查生产依赖：

    npm audit --omit=dev

应用兼容的安全更新并刷新锁文件：

    npm audit fix --package-lock-only

## HTTP 接口

- GET / — 普通页面
- GET /legacy — 精简页面
- GET /healthz — 健康检查
- /api/zhibo/* — 新浪 7x24 接口代理
- GET /api/avatar?url=... — 白名单头像代理
